# Changelog

## 0.1.0 — 2026-09-26

First release.

- Virtual keys in a `/crates` menu, physical key items, and `/tc keyall` for events
- Three opening animations: a roulette menu, an in-world display above the crate, or instant
- Crate labels as text display holograms, no hologram plugin needed
- `/tc additem` adds the item in your hand exactly as it is (names, enchantments, custom model data)
- Reward preview with chances, broadcasts and command rewards
- The reward is rolled when the crate opens and is granted even if the menu is closed early or the player logs out mid-animation
- Keys can't be placed or used in crafting; crate blocks survive explosions and pistons
- MiniMessage everywhere, example crates included
- Paper 1.21.4 – 26.x and Folia
